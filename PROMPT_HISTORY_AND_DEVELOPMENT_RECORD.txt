PART 4: OASIS RECOGNITION TASKS


TASK 1: VAE

AI assistance was used to help design and debug the convolutional VAE for the
OASIS brain MRI images.

The implementation used:
- grayscale OASIS MRI images;
- 64 x 64 input images;
- a 2-dimensional latent space;
- an encoder and decoder using convolutional layers;
- reconstruction loss and KL divergence; and
- sampling from the latent space.

The model was trained on Rangpur using an A100 GPU.

The final training used 30 epochs and 9664 training images. The training loss
decreased from approximately 1276.45 to 1047.85.

The trained model was then used to produce:
- reconstructed MRI images;
- a latent-space visualisation; and
- samples generated from the 2D latent space.

The results were visually checked to make sure the latent samples produced
brain-like structures and showed variation.

Relevant files include:

oasis_vae.py
oasis_vae_job.sh
oasis_vae_visualize.py


TASK 2: U-NET

AI assistance was used to help develop and debug the U-Net segmentation model
for the OASIS dataset.

The implementation was adapted to the four mask classes in the dataset:
- background;
- label 1;
- label 2; and
- label 3.

The segmentation masks were converted into class indices and the network
produced four categorical output channels.

The model used an encoder-decoder U-Net structure with skip connections.

The model was trained on Rangpur using an A100 GPU for 40 epochs.

The best validation result achieved:

Mean DSC: 0.9663
Background DSC: 0.9996
Label 1 DSC: 0.9404
Label 2 DSC: 0.9528
Label 3 DSC: 0.9724

The predictions were visualised by comparing the original MRI, predicted
segmentation and overlay.

Relevant files include:

oasis_unet.py
oasis_unet_job.sh
oasis_unet_visualize.py


TASK 3: GAN

AI assistance was used to help develop and debug a DCGAN-style model for
generating OASIS brain MRI images.

The implementation used:
- 64 x 64 grayscale images;
- a 100-dimensional latent vector;
- a convolutional generator;
- a convolutional discriminator;
- batch normalisation;
- spectral normalisation in the discriminator;
- hinge GAN loss; and
- Adam optimisation.

The model was trained on Rangpur using an A100 GPU for 50 epochs.

The training took approximately 210.34 seconds.

Generated samples were saved throughout training so that the progression of
the generator could be checked.

The final samples showed brain MRI-like structures with visible variation
between generated images. The training progression was also checked for signs
of mode collapse.

Relevant files include:

oasis_gan.py
oasis_gan_job.sh
gan_progression.py
