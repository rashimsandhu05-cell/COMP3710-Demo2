# AI Declaration

AI tools, mainly ChatGPT, were used as a support tool during the development of this lab demonstration.

I used AI mainly for:
- understanding concepts and requirements from the lab;
- getting help with Python and PyTorch implementations;
- debugging code and fixing errors;
- getting help with Rangpur and Slurm job scripts;
- understanding model architectures and training methods; and
- improving the organisation and documentation of the project.

For the DFT, Eigenfaces, CNN and DAWNBench sections, AI was used to help understand the required implementations and troubleshoot code where needed.

For the OASIS tasks, AI was used to assist with developing and debugging the VAE, U-Net and GAN implementations. I adapted the code to the OASIS dataset and the requirements of the lab, then ran the training and visualisation jobs myself on Rangpur and checked the results.

I also used AI while working on Git and GitHub organisation, including help with repository structure, commit organisation and documentation.

The final code and results were tested by me. I reviewed the generated suggestions, made changes where necessary, and I am responsible for understanding and explaining the submitted work.
